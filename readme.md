# Cube Playground

Интерактивное мини-приложение для управления кубиками на площадке.

## 🔗 Ссылка на демо

👉 https://denischernykh.github.io/cube-playground/

## 📋 Функциональность

Приложение реализует все требования из тестового задания:

1. Площадка 800×800 пикселей.
2. Два интерактивных кубика.
3. Перетаскивание кубиков по X и Y.
4. Ограничение перемещения внутри площадки.
5. Выбор кубика кликом.
6. Изменение цвета выбранного кубика (3 цвета).
7. Приближение кубиков приводит к "прилипанию".
8. Прилипшие кубики перемещаются вместе.
9. Кнопка "Разъединить" — кубики отлетают в разные стороны.

## ⚙️ Используемые технологии

- HTML, CSS, JavaScript (vanilla)
- Без библиотек и фреймворков
- Анимации реализованы через `requestAnimationFrame`

## 📁 Структура

- `index.html` — основной файл
- Все стили и скрипты инлайн — для простоты публикации
